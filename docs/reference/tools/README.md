# Tool and Reference Research

This directory contains offline, project-specific research notes for every important tool/reference used in the Mermaid Diagrams plan. It does not contain vendored source code.

- `catalog.md` — one-page selection and adoption matrix.
- `sources-lock.md` — URLs and version/commit fields to pin during Phase 00.
- `docs/<tool>/overview.md` — what the tool is.
- `docs/<tool>/architecture.md` — how it is structured and relevant technical boundaries.
- `docs/<tool>/adoption-for-mermaid-diagrams.md` — what to adopt, reject, test, and in which phases.
- `cross-tool-synthesis.md` — how the tools fit together and where responsibilities must not overlap.

Each tool folder intentionally contains no more than three Markdown files.
