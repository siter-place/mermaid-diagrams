# WordPress Agent Skills — Adoption for Mermaid Diagrams

## Adopt

- Install all published skills at project scope or ensure they are available to Cursor.
- Run router and triage at every phase start.
- Map specialist skills to phase work and record which were used.
- Use ability audit/verify skills as release gates, not merely design reading.

## Do not adopt blindly

- Do not treat generic skill advice as permission to override final product decisions.
- Do not claim a skill was used unless its procedure and verification were actually followed.
- Do not vendor a stale snapshot invisibly; update deliberately and review diffs.
## Acceptance evidence

- The relevant phase cites this research and records the selected version/API.
- Automated tests protect every adopted behavior that affects persistence, permissions, rendering, or public contracts.
- Documentation names the fallback when the tool/dependency is missing or incompatible.
- No unreviewed source copy is introduced.

## Decision state

Planned use: **All phases; especially 00, 01, 02, 06, 07, 10, 11, and 13.**. Final dependency selection is confirmed in Phase 00 or the first phase that implements the integration.
