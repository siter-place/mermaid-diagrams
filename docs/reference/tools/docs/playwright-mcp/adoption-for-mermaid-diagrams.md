# Playwright MCP — Adoption for Mermaid Diagrams

## Adopt

- Configure in Cursor inside WSL.
- Use to explore wp-env, reproduce issues, discover semantic locators, and design tests.
- Convert successful exploratory workflows into committed Playwright Test files.

## Do not adopt blindly

- MCP sessions are not release evidence.
- Do not persist production cookies or secrets in browser profiles.
- Do not make tests depend on a human/MCP agent being available.
## Acceptance evidence

- The relevant phase cites this research and records the selected version/API.
- Automated tests protect every adopted behavior that affects persistence, permissions, rendering, or public contracts.
- Documentation names the fallback when the tool/dependency is missing or incompatible.
- No unreviewed source copy is introduced.

## Decision state

Planned use: **00 and UI phases 04–13.**. Final dependency selection is confirmed in Phase 00 or the first phase that implements the integration.
