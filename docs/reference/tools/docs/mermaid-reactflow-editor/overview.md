# Mermaid React Flow Editor — Overview

**Canonical source:** https://github.com/albingcj/mermaid-reactflow-editor  
**Role in this project:** Visual flowchart editing research reference  
**Research date:** 2026-08-01

## What it is

React/Vite application that maps Mermaid flowchart structures to React Flow nodes/edges, supports graph interactions, and serializes edits back toward Mermaid syntax.
