# Merpress — Adoption for Mermaid Diagrams

## Adopt

- Review block ergonomics, build layout, preview error states, and practical browser export issues.
- Use as regression inspiration, not architecture.

## Do not adopt blindly

- It does not provide the central library, dedicated Svelte editor, enterprise REST services, abilities/MCP, usage index, or taxonomy workflows.
- Do not inherit any CDN or loose-security assumptions.
## Acceptance evidence

- The relevant phase cites this research and records the selected version/API.
- Automated tests protect every adopted behavior that affects persistence, permissions, rendering, or public contracts.
- Documentation names the fallback when the tool/dependency is missing or incompatible.
- No unreviewed source copy is introduced.
