# WP Mermaid — Adoption for Mermaid Diagrams

## Adopt

- Use conditional asset-loading ideas and compatibility fixtures.
- Review graceful no-diagram frontend behavior.

## Do not adopt blindly

- Shortcodes and legacy content models are out of scope for 1.0.
- Do not copy outdated Mermaid versions or global rendering assumptions.
- It is not a library/editor architecture.
## Acceptance evidence

- The relevant phase cites this research and records the selected version/API.
- Automated tests protect every adopted behavior that affects persistence, permissions, rendering, or public contracts.
- Documentation names the fallback when the tool/dependency is missing or incompatible.
- No unreviewed source copy is introduced.

## Decision state

Planned use: **Research in 00; frontend asset review in 07.**. Final dependency selection is confirmed in Phase 00 or the first phase that implements the integration.
