# Phase 07 Tests and Acceptance

## PHP unit/integration

- [ ] Public payload/source authorization.
- [ ] Download flags and front-end asset conditions.
- [ ] Unique context/IDs for multiple blocks.

## JavaScript/Svelte unit tests

- [ ] Interactivity store actions/derived state.
- [ ] Independent instances.
- [ ] Fullscreen/fallback/focus.
- [ ] Download filenames/blobs and cleanup.
- [ ] Keyboard/pointer pan/zoom constraints.

## Bruno REST tests

- [ ] Public/private diagram access and download endpoint policy.

## Playwright and visual tests

- [ ] Zoom/pan/fit/reset.
- [ ] Native/fallback fullscreen and focus return.
- [ ] Source/SVG download content/filename.
- [ ] Two diagrams independent.
- [ ] Mobile/RTL/high-contrast/reduced-motion visual snapshots.

## Acceptance outputs

- [ ] No public React root.
- [ ] Frontend bundle/performance budgets pass.
- [ ] Controls meet keyboard/focus/label requirements.
- [ ] Unauthorized source/content is absent.

## Required evidence

- Exact commands and exit status.
- Test/report artifact locations.
- Screenshots/traces only for intentional UI evidence or failures.
- Before/after API/schema example when a public contract changes.
- Database migration/version evidence when storage changes.
- Accessibility and performance evidence when applicable.
- List of deferred items mapped to a later phase, not vague TODOs.

## Exit rule

Do not mark this phase complete while a required test is skipped without an approved, dated reason and target phase.
