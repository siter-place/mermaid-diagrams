# Test Suites

- `phpunit/` — pure domain/application unit tests.
- `integration/` — WordPress integration, REST, block, cron, media, ability tests.
- `js/` — Mermaid runtime, React, Svelte, adapter and state-machine tests.
- `e2e/playwright/` — committed browser and visual regression tests.
- `../bruno/` — black-box REST workflow collection.

The detailed coverage plan is in `docs/09-testing-strategy.md` and each phase's `tests-and-acceptance.md`.
